# Use Cases

## 1. View Available Rooms
- Actor: Student
- Steps:
  1. Open the app
  2. Select date and time
  3. View available rooms

## 2. Book a Room
- Actor: Student
- Steps:
  1. Log in
  2. Select date and time
  3. Choose a room
  4. Click "Book"
  5. See confirmation

## 3. Cancel a Booking
- Actor: Student
- Steps:
  1. Go to "My Bookings"
  2. Select a booking
  3. Click "Cancel"
